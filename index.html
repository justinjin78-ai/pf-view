계좌
데이터 업데이트
1) 폴더의 업데이트.bat 더블클릭 → 계좌별 잔고가 수집되고 오늘 날짜 스냅샷이 저장됩니다.
2) 완료되면 이 페이지를 새로고침(F5) 하세요. (데이터 파일은 페이지를 열 때 한 번 읽습니다)
3) 같은 날 여러 번 실행하면 그날 스냅샷은 마지막 값으로 덮어씁니다.
4) 배당 기록(거래내역)도 함께 수집됩니다. 첫 실행은 전체 기간이라 1~2분, 이후는 최근 1주일만 다시 받습니다.
연금저축·ISA는 API 미지원 → 아래 '수동 계좌'에 총액을 직접 기록합니다.
5) 연금저축·ISA 자동 반영: HTS 국내 잔고를 수동엑셀 폴더에 계좌이름.xlsx(예: 연금저축1.xlsx)로 저장 → 업데이트.bat(또는 07:00 자동 수집) → 새로고침하면 종목까지 기록됩니다. 기준일 = 파일 저장 날짜, 예수금은 직전 기록값 유지.
